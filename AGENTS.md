# Regras do projeto

- Desenvolva um site de portfólio pessoal em HTML, CSS e JavaScript puro, sem frameworks.
- Antes de criar ou alterar qualquer coisa, leia `referencias.md`, `identidade.md` e `funcionalidades.md`.
- Mantenha o código organizado em um arquivo HTML, um arquivo CSS e um arquivo JavaScript, com as seções do HTML identificadas.
- Não crie um layout genérico de template: siga as referências e a identidade visual descritas nos arquivos do projeto.
- O site deve ser responsivo e funcionar bem em computadores e celulares.
- Não remova funcionalidades existentes nem reescreva partes que já funcionam para realizar alterações pequenas.
- Implemente e teste uma funcionalidade por vez, seguindo a ordem de prioridade de `funcionalidades.md`.
- Não invente informações pessoais, experiências profissionais, certificados, clientes ou projetos.
- Use imagens próprias ou imagens com licença adequada. Para a foto pessoal, deixe um espaço reservado até que eu forneça uma imagem.
- Respeite acessibilidade, contraste, navegação por teclado e a preferência por movimento reduzido.
- Depois de cada mudança, explique em 2 linhas o que foi feito e liste os arquivos alterados.
- Na primeira etapa, crie somente a seção inicial (Hero). Não desenvolva as outras seções até eu aprovar a primeira etapa.
